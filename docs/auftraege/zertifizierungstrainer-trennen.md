# Zertifizierungstrainer trennen

Die Salesforce-Vorbereitung verbleibt in diesem Repository. Die HubSpot-Vorbereitung erhält ein eigenes Repository und einen eigenen Projektordner.

- Beide Apps lassen ihre Lernpfade direkt auswählen und laden jeweils ihre eigenen Lerninhalte.
- Die Trainer speichern Fortschritt unabhängig voneinander. Beide können ihre Datensätze aus einer Sicherung der gemeinsamen App übernehmen.
- Der Browser-Test prüft Lernpfadauswahl, Navigation, Mini-Prüfung und Migration für beide Trainer.
